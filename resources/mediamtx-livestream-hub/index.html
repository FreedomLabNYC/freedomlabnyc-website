MediaMTX Livestream Hub

SkillStreamingSelf-HostedMediaMTX

Own your stream: one RTMP ingest, HLS out to viewers, restream fan-out to platforms without re-encoding, Nostr NIP-72 announce — all on your own server.

Download mediamtx-livestream-hub.skill

Brief overview

Frontends come and go; the stream should live on your infrastructure. This skill runs an agent through the MediaMTX hub: end-to-end ingest checks with synthetic test streams before touching config, recording budget math, publisher fan-out to X/YouTube/Twitch as pure stream copies, and an announce layer where one signer identity is shared between CLI and web UI.

What this skill teaches your agent

  • Synthetic ffmpeg ingest → HLS master playlist verification, and the ?session= redirect dance on MediaMTX ≥1.18
  • Host-side config mounted read-only; enum validation because bad values crash-loop the container
  • Disk-budgeted recording paths
  • publishers: restream fan-out setup
  • Announce identity: one signer across CLI and sidecar, per-relay read-back tests
  • Container rebuilds that preserve mounts; control-server port-fight traps

What's included

  • SKILL.md — full agent instructions

Install

Download the .skill bundle, unpack it, and point your agent (Hermes, Claude Code, or any AgentSkills-compatible agent) at the folder containing SKILL.md. The canonical source lives in the FreedomLabNYC catalog — pull updates there for the current version.
