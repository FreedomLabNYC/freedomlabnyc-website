Local Voice Transcription for AI Agents

SkillWhisperLocal AIPrivacy

Voice messages in, text out — fully local. faster-whisper transcription with optional Ollama analysis: summaries, action items, key points.

Download voice-transcribe.skill

Brief overview

Handles ogg/opus/mp3/wav/m4a/flac — the formats voice messages actually arrive in from Telegram, WhatsApp, and Discord. Everything runs on your own CPU with int8 quantization; language is auto-detected; nothing leaves the machine. Optional Ollama passes add summarization, action-item extraction, and speech-to-text error enhancement.

What this skill teaches your agent

  • One-time venv setup and the model-size ladder: tiny (~32x realtime) through large-v3
  • Quick transcription CLI with text/json/srt output and per-segment timestamps
  • Transcription + analysis pipeline with --enhance and --analysis-type flags
  • Workflow rules: when to quote full text vs summarize, handling long outputs

What's included

  • SKILL.md — full agent instructions
  • scripts/transcribe_voice.py — transcription engine
  • scripts/transcribe_with_analysis.py — Ollama analysis pipeline

Install

Download the .skill bundle, unpack it, and point your agent (Hermes, Claude Code, or any AgentSkills-compatible agent) at the folder containing SKILL.md. The canonical source lives in the FreedomLabNYC catalog — pull updates there for the current version.
