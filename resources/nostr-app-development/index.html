Nostr App Development for AI Agents

SkillNostrAI AgentsWeb Apps

Everything an agent needs to ship working Nostr features — publishing, feed readers, verification — with the relay behaviors that break naive implementations.

Download nostr-app-development.skill

Brief overview

Nostr clients look simple; relays are not. damus-class relays silently never answer OK, nostr.wine gates writes behind signup, redirects kill NIP-05 verification, and an OK-true reply does not mean your event is queryable. This skill is the distilled operational truth from shipping real relay read/write paths.

What this skill teaches your agent

  • Raw NIP-01 WebSocket REQ/EVENT/EOSE/CLOSE patterns per relay, fan-out with non-fatal failures
  • Relay quirks table: restricted writes, transient 503 handshakes, addressable-event #a filters
  • Headless verification workflow on Node 22 (no browser) and a stdlib Python probe
  • NIP-05 self-hosted verification: nostr.json rules, lowercase-hex pubkeys, CORS header, ACME/Cloudflare interactions
  • NIP-72 livestream (kind 30311) announce/revoke, public image tags, server-side state persistence
  • Publish→read-back timing and when to stop repeating probes

What's included

  • SKILL.md — full agent instructions
  • scripts/nostr_probe.py — stdlib-only relay probe (author + kinds → events, no dependencies)
  • references/caddy-static-serving.md — public HTTPS thumbnail serving behind Cloudflare

Install

Download the .skill bundle, unpack it, and point your agent (Hermes, Claude Code, or any AgentSkills-compatible agent) at the folder containing SKILL.md. The canonical source lives in the FreedomLabNYC catalog — pull updates there for the current version.
