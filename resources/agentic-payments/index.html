Abstract

The web was built with a slot for payments, and that slot was left empty. Card networks filled the gap instead, and cards need a human to blame when something goes wrong. Agents have now arrived, and the payment layer still demands that human.

This session walks through what an agent actually needs in order to pay for something, why the existing rails cannot give it, and which new rails are being built. It covers x402, L402, and the Lightning work that predates both, then runs every option through the same five tests, so you can judge a rail yourself instead of taking a vendor's word for it.

It ends with the practical part: getting your own agent a wallet it holds the keys to.

Resource Links

Directories and explorers

  • 402index.io. An index of services that take x402 payments, so you can see what an agent can buy today.
  • x402scan.com. An explorer for x402 payment activity, useful for checking whether a rail is really being used.

Give an agent a wallet

  • docs.moneydevkit.com/agent-wallet. Money Dev Kit's guide to giving an agent a wallet of its own.
  • docs.wdk.tether.io/ai/x402/. Tether's Wallet Development Kit docs for wiring x402 into an AI agent.

L402, the Lightning-native standard

  • l402.org. The home page for L402, the paid HTTP standard built on Lightning.
  • github.com/l402-protocol/l402. The L402 specification and its reference material.
  • docs.lightning.engineering/the-lightning-network/l402. Lightning Labs' own L402 documentation, from the team that shipped it in 2019.
  • github.com/Fewsats/awesome-L402. A curated list of L402 tools, libraries, and working implementations.

Put a paywall in front of an API

  • lightningenable.com. A service for adding Lightning payments to an API you already run.
  • lightningprox.com. A proxy that sits in front of an API and charges per request.
  • aiprox.dev. A proxy aimed at pay per call access to AI model endpoints.

Live things to point an agent at

  • api.bitcoinbenji.com. A paid API you can use to test an agent payment from end to end.
  • unhuman.shopping. A storefront built for agents to buy from, rather than for people to browse.

Reading and what comes next

  • Open source AI needs to get serious, from Spiral. The argument for why open source AI has to solve payments.
  • wavelength.lightning.engineering. Lightning Labs' Wavelength, aimed at machine to machine payments at very small amounts.
