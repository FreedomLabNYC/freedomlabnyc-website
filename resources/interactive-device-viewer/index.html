Interactive 3D Device Viewer

SkillThree.jsWebsitesPlaywright

Teach your agent to add 3D device studies, run real-browser QA, and publish to a live site — using the voicehardware exploded-assembly page on freedomlab.nyc as the worked example.

Download interactive-device-viewer.skill

Brief overview

Every viewer device on the voicehardware page is a hand-built Three.js exploded assembly with source-grounded measurements: exterior numbers quoted from manufacturer drawings, internals labeled as photo-estimated, screen content marked illustrative. This skill encodes the whole operating loop: model authoring in hardware-models.js, surgical edits to minified single-line HTML, the Playwright QA suite at desktop and phone viewports, and the copy-audit-poll publish flow to the live site.

What this skill teaches your agent

  • Add a new device study: buildModel branch, required part ids, canvas label textures, round-panel geometry gotchas
  • Edit minified one-line HTML safely: marker-slice + assert count==1, the \uXXXX raw-string trap
  • Renumber devices without breaking jump-nav, SEO copy, or QA assertions
  • Cache-buster discipline and CSS md5 convention
  • Run verify_site.py (real Chromium, two viewports) and read its output
  • Publish: diff the source site into the Pages repo, build + audit scripts, push, poll the live cache-buster, prove videos serve 206
