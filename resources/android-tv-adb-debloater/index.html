Brief overview

Disabling NVIDIA telemetry with pm disable-user silently reverts at boot; the method that persists is a targeted per-user uninstall with a saved undo script. This skill carries that kind of field truth: the never-touch package list, HOME-role swap verification that does not lie, D-pad-only system pickers where taps go ignored, real video-wallpaper constraints in Couchy launcher, aerial-style custom scenes for tvOS Launcher, and a stills→loop ffmpeg pipeline with corruption-safe validation.

What this skill teaches your agent

  • Persistent debloat via pm uninstall --user 0 + install-existing undo scripts; safe deny-list
  • Animations kill via settings put global (no UI toggle exists on Android TV)
  • Launcher HOME swap end-to-end verification with dumpsys
  • Couchy launcher: SAF-picker-only video wallpaper, LiteTV log triage
  • tvOS Launcher: frame-extraction scenes, string-sort filename traps, safety posture
  • Stills→aerial loop ffmpeg recipes: zoompan chains, blur-fill backgrounds, moov-atom validation
  • Screencap-diff motion proof (and why exec-out screencap corrupts PNGs)
