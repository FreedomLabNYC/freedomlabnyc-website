Brief overview

The Hermes Gadget SDK (MIT, community-tier) runs on Waveshare ESP32-S3 LCD/AMOLED boards and similar hardware. This skill covers the whole bring-up: choosing browser-installer vs source build, identifying the exact board revision from the order page SKU, OTA updates, and the failure modes that eat afternoons — stale espressif32 platform pins, serial-group permissions on Arch, hidden setup SoftAPs, silent firewall drops, and audio that is not broken, just unplugged.

What this skill teaches your agent

  • Prerequisite checks before touching hardware (plugin, STT/TTS, gateway ws listener)
  • Board identification from the manufacturer SKU → PlatformIO env name
  • Three flash paths: browser installer, source build, OTA update with rollback
  • Serial permission recipe without re-login — and why sudo pio upload poisons the build tree
  • Pairing flow: auth URL → device approval → pairing code → home-channel warning
  • Verification without serial: esptool hash lines, status JSON, screencap logic
  • Board-specific depth: ESP32-S3-Touch-AMOLED-1.75 chip/pin map, I2C scan list, touch gesture table

What's included

  • SKILL.md — full agent instructions
  • references/waveshare-amoled-175.md — silicon map + first-flash verification checklist
